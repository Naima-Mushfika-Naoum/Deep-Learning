# Deep-Learning

A comprehensive collection of Jupyter Notebooks, datasets, and visual resources covering foundational to advanced Deep Learning concepts using **Python**, **TensorFlow**, and **Keras**.

---

## 📌 Repository Overview

This repository contains practical implementations ranging from neural network fundamentals and optimization algorithms to image classification and handling overfitting.

| File Name | Description |
| :--- | :--- |
| **`Activation Function.ipynb`** | Detailed analysis and implementation of core activation functions (ReLU, Sigmoid, Tanh, Softmax). |
| **`Bank_Customer_Satisfication_Using_CNN.ipynb`** | Classification model leveraging 1D Convolutional Neural Networks (CNN) to predict customer satisfaction. |
| **`Code for Hand digit.ipynb`** | Handwritten digit recognition (MNIST benchmark) built using basic artificial neural network (ANN) architecture. |
| **`Data_Augmentation_to_Address_Overfitting_in...ipynb`** | Practical guide to image augmentation techniques used to prevent model overfitting. |
| **`Gradient Descent.ipynb`** | Step-by-step mathematical breakdown and implementation of Gradient Descent optimization. |
| **`Starting with tensorflow-checkpoint.ipynb`** | Getting started with TensorFlow fundamentals, tensor manipulations, and Keras API setup. |
| **`Insurance_data.csv`** | Primary dataset used for simple neural network regression and classification examples. |
| **`Flatten.png` / `nn.png`** | Diagrammatic representations of neural network architectures and layer flattening processes. |

## 🛠️ Requirements & Setup

### Prerequisites
Make sure you have Python 3.8+ installed along with Jupyter Notebook or JupyterLab.

### Installation
Clone this repository and install the necessary dependencies:

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/Deep-Learning.git

# Navigate into the project folder
cd Deep-Learning

# Install required packages
pip install tensorflow keras numpy pandas matplotlib jupyter
```

---

## 🚀 How to Run

1. Launch Jupyter Notebook from your terminal:
   ```bash
   jupyter notebook
   ```
2. Open any `.ipynb` file to run the cells interactively.
